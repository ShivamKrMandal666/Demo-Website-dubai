 Migrate to Next.js Stack + Clean Up + Install Tooling

## Context

This codebase was generated by Emergent AI and was interrupted mid-task before it finished building the Treatments page and individual treatment pages. It currently uses **Vite + React, FastAPI (Python) backend, and MongoDB** — none of which is the intended stack for this project. The intended stack is:

**Next.js (TypeScript, App Router) + Tailwind CSS + Motion.dev + Lenis**

The 29 generated/optimized images in `public/images/` (treatment images, hero backgrounds, section backgrounds) are correct and must be preserved exactly as-is — do not regenerate or touch them.

## Task

Migrate this entire codebase from Vite + React to **Next.js (App Router, TypeScript)**, while keeping the final result visually and behaviorally identical to what currently exists — same layout, same UI, same colors/typography, same animations, same hover effects, same scroll behavior. This is a stack conversion, not a redesign.

**Specifically:**

1. **Framework migration**
   - Convert the Vite + React app into a Next.js (App Router) project using TypeScript throughout
   - Recreate the existing pages/routes as Next.js App Router routes
   - Convert components to server components by default; add `"use client"` only where interactivity (animation, hover, carousels, scroll) requires it
   - Preserve every existing page, section, layout, and component exactly as it currently looks and behaves — no visual or structural regressions

2. **Animation/scroll migration**
   - Replace Framer Motion usage with **Motion.dev**, keeping the same animations, transitions, and hover effects — timing, easing, and feel should match what's currently there
   - Keep **Lenis** for smooth scroll (already present) — make sure it's correctly initialized once at the root layout level in the new Next.js structure
   - Verify all scroll-triggered reveal animations and hover effects still work exactly as before after migration

3. **Remove backend and unwanted files**
   - Fully remove the FastAPI (Python) backend and all related files/folders
   - Fully remove MongoDB integration and any related dependencies/config
   - Remove all Emergent-specific files, plugins, and boilerplate that aren't needed going forward (e.g. Emergent visual-edits plugin, Emergent health-check plugin, and any other Emergent-only tooling/config)
   - Remove any now-unused dependencies from `package.json` after the framework and backend changes (audit and clean up rather than leaving dead packages installed)

4. **Preserve and reuse**
   - Keep all 29 images in `public/images/` and any image manifest/organization already set up — do not regenerate them
   - Keep shadcn/ui components already in use
   - Keep Tailwind CSS setup, converting config as needed for the Next.js project structure

5. **Install and configure tooling**
   - Install and configure the following Claude Code plugins/skills for this project: **UI UX Pro Max**, **Impeccable**, **Superpowers**, **Feature Dev**
   - Add **Vengeance UI** and **shadcn/ui** as the component libraries going forward (shadcn/ui is already partially in use — keep it; add Vengeance UI alongside it)

6. **Quality bar**
   - Fix any errors introduced during migration — the app must build and run cleanly (`npm run build` passes)
   - Fast load: images stay optimized, no unnecessary re-renders or bundle bloat introduced during the migration
   - End state should be indistinguishable from the current UI/UX to a visitor, just running on the correct stack
